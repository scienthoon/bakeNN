# Support

Use GitHub Issues for reproducible bugs and scoped operator or target requests.
Before filing, check the current support matrix and intentional constraints in
the README. Include the smallest model and exact error rather than only a model
family name.

BakeNN does not currently provide commercial support, guaranteed response
times, dynamic-shape execution, a runtime model loader or universal parity with
the TFLM operator catalog. Security-sensitive reports belong in the private
channel described in `SECURITY.md`.
